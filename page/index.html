Gamepad bar planner

Plan WoW Forever's gamepad bars for any class and controller, then put the layout in the game with the PadPlan addon. Your layouts are saved in this browser. Source and addon
How to use this
  1. Pick your class and controller, and your level (spells you can't use yet are dimmed). Or start from a built-in layout in the Layout list.
  2. Drag spells from the list on the right onto the slots. The picture is drawn like the game's: the middle cluster is what you get with no trigger held, the left one with LT held, the right one with RT, the bottom one with both. Hover anything to see what it is.
  3. Back buttons (optional): tick "Back buttons" to use your controller's back buttons as more slots. This needs the free SNRN Backhand addon.
  4. Get it into WoW: install the PadPlan addon, give it this layout (a file or a code), then log in. It puts everything in place by itself. See "Get it into WoW" below.
  5. Steam: if you use back buttons, set them up in Steam as the "Steam Input" steps below say.

Built-in layouts are read-only. Change anything and it becomes your own copy.

Shows the back-button slots in the picture.

With no trigger held, the face buttons belong to the game (interact, inspect, back, jump), so they can't hold spells. Drag a spell onto a slot, drag between slots to swap, right-click a slot to empty it. On a touch screen, tap a spell and then a slot; hold a slot or spell to see what it is.

Back buttons

Each back button is an extra slot on every trigger layer, drawn as the round 2 x 2 grid above each cluster, the way it looks in game. They're the same in all three sets. Mark a button as used by something else to keep it free.

What you need

    Get it into WoW

    1. Install the PadPlan addon: download PadPlan.zip and unzip it into World of Warcraft/_forever_/Interface/AddOns/. If you use back buttons, install SNRN Backhand the same way.
    2. Give PadPlan this layout. There are two ways; they do the same thing, so pick one.
      A small file holding this layout. Put it in World of Warcraft/_forever_/Interface/AddOns/PadPlan/, replacing the one there. No typing in game, so it suits playing with only a controller.
      This layout as one text code. In game, type /padplan import, paste it and press Import (needs a keyboard). The same code also works in anyone's planner: Import, then paste.
    3. Log in, or log out to the character list and back in. PadPlan puts every spell in place by itself, sets up the back buttons, and says what it did in chat. Spells you haven't learned yet go on by themselves when you learn them.

    Macros in a layout become character macros named PP ..., so they need free character macro slots.

    Share and back up

    To share a layout, send its layout code ("Copy layout code" above). Anyone can paste it into this page with Import, or into WoW with /padplan import.
