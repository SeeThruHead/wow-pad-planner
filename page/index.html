Gamepad bar planner

Plan WoW Forever's gamepad bars for any class and controller. Layouts are saved in this browser. Source and addon

Built-in layouts are read-only. Change anything and it becomes your own copy.

Shows the back-button slots in the HUD.

With no trigger held, the face buttons belong to the game (interact, inspect, back, jump), so they can't hold spells. Drag a spell onto a slot, drag between slots to swap, right-click a slot to empty it. On a touch screen, tap a spell and then a slot.

Back buttons

Each back button becomes an extra slot on every trigger layer, drawn as the round 2 x 2 grid above each cluster, the way Backhand shows it in game. They're the same in all three sets. Mark a button as used by something else to keep it free.

      Putting it in the game

      1. Install the PadPlan addon: unzip it into World of Warcraft/_forever_/Interface/AddOns/. For the back-button slots, also install SNRN Backhand.
      2. Press Copy code for the addon. In game, type /padplan import, paste the code (Ctrl+V) and press Import. The addon keeps it for that character.
      3. In gamepad mode and out of combat, type /padplan apply. It places every slot of all three sets the way the gamepad bar's own edit mode does, so the server keeps them. /padplan check lists slots that differ from the layout.
      4. Spells you haven't learned yet are skipped. Run /padplan apply again after a trainer visit; spells always go on at their highest rank.
      5. Macros become character macros named PP ..., so they need free character macro slots.
      6. Prefer a file? Download PadPlanData.lua and put it in the PadPlan folder instead; an imported code takes priority until /padplan forget.
